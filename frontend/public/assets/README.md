# Custom art drop-in

Empty on purpose. Add files here with these exact names to replace the CSS/emoji
defaults — see the "Visual style / custom art" section in the repo root `README.md`:

- `backyard-bg.jpg` — full-screen table backdrop
- `card-back.png` — card back design
- `avatar-0.png` through `avatar-5.png` — per-seat player avatars
